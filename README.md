# The Lounge Clean Chat

Custom CSS for [The Lounge](https://thelounge.chat/) focused on making the DarkPeers IRC experience cleaner and easier to read, especially where the website chat is bridged into IRC.

This project is deliberately **CSS-only**. It does not patch The Lounge, the DarkPeers bridge, Docker images, JavaScript or the giveaway userscript.

**Current version:** v0.3.1  
**Tested with:** The Lounge 4.5.2  
**Browsers tested:** Chrome on Android and desktop

## Scope

v0.3.1 is explicitly scoped to the **DarkPeers** IRC network.

Expected setup:

```text
Network:     DarkPeers
Main channel:#darkpeers
Bridge bot:  DP
```

The stylesheet detects the currently active network from The Lounge's sidebar DOM and applies its runtime styling only while a DarkPeers target is active.

This means similarly named channels on other connected IRC networks are left untouched. For example, a `#announce` channel on another network no longer inherits DarkPeers-specific preview suppression.

The only intentionally global rule is the larger **Custom CSS editor**, because that editor belongs to The Lounge itself rather than to any IRC network.

## What it does

- Replaces the `DP` bridge nickname with a compact **WEB** badge in `#darkpeers`.
- Gives bridged website messages a subtle visual treatment.
- Detects likely bridged replies and adds a reply indicator.
- Replaces long DarkPeers URLs with compact labels such as `profile ↗`, `thread ↗`, `request ↗` and `BON pool ↗`.
- Hides useless unauthenticated UNIT3D `Login / Powered by UNIT3D` link previews.
- Keeps useful image/GIF previews while shortening direct media URLs.
- Uses stricter media URL matching to avoid false positives.
- Preserves direct media hosted on `darkpeers.org` instead of treating it as a generic site link.
- Improves inline image sizing and spacing.
- Hides join/part/quit noise in `#darkpeers` while keeping topic changes visible.
- Avoids orphaned **New messages** markers when only hidden presence events follow them.
- Reduces timestamp and hostmask visual noise.
- Adds mobile-specific readability improvements.
- Expands the real formatted channel topic on touch devices.
- Contains touch-topic overscroll so the background chat is less likely to move while reading a long topic.
- Makes The Lounge's Custom CSS editor larger.
- Hides link/media previews in the DarkPeers bot-only `#announce` and `#pre` channels.
- Adds giveaway-aware styling for messages generated by the **Blutopia BON Giveaway** userscript when their emoji markers survive the DarkPeers → IRC bridge.

## Giveaway-aware styling

The Lounge preserves emoji as structured `.emoji` spans even after the DarkPeers bridge strips the original BBCode colours. TLCC uses those surviving markers as CSS-only heuristics.

Current treatments include:

- `GIVEAWAY` — main giveaway announcement and reminders (`🎁` + `✨`).
- Gold WEB treatment — sponsor update digests (`✨`).
- `ENTRIES` — current entries list (`📋`).
- `TIME` — remaining-time response (`⏳`).
- `SPONSORS` — final sponsor thank-you when it is immediately followed by the tie/result sequence (`🥳`).
- `RESULT` — final winner summary (`🏆`).
- `TIE` — tie-break announcements (`⚠️`).
- `RIGGED` — rigged-mode announcements / marked rigged entries (`😈`) and rigged main reminders (`😉` combined with the normal giveaway signature).
- `UNRIGGED` — successful rigged-mode disable message (`😒`).
- `NAUGHTY` — naughty-list add/removal marker (`👮`).
- `ALERT` — rejected or unauthorised actions marked with `🚫`, `🛑` or `🚨`.

The giveaway palette is centralised in `--tlcc-*` custom properties so it is easier to maintain without changing the selector logic.

## Installation

1. Open **The Lounge**.
2. Go to **Settings → Appearance → Custom CSS**.
3. Copy the contents of [`thelounge-clean-chat.css`](thelounge-clean-chat.css).
4. Paste it into the Custom CSS field and save.

For inline URL/image previews, The Lounge's normal link prefetch/media preview functionality must be enabled.

## DarkPeers network name

The network scope expects the The Lounge network/lobby label to be:

```text
DarkPeers
```

If your local The Lounge connection is named differently, change:

```css
[data-name="DarkPeers" i]
```

to your local network name.

The DarkPeers main-channel and bridge selectors are case-insensitive in v0.3.

## Limitations

Website usernames such as `[Furyan]` or `[Chungus]` are plain text sent by the bridge. CSS cannot turn those substrings into native The Lounge nickname elements, assign them native nick colours, or make them open The Lounge's user context menu.

The same limitation applies to other bridge text that merely looks like markup. The project deliberately stays **CSS-only**.

Giveaway detection has the same constraint: only structure that survives the bridge can be selected reliably. CSS cannot safely identify text-only giveaway replies such as `Giveaway Amount`, normal entry confirmations, `your number is`, winner-scaling messages or time adjustments unless they also contain a distinctive structured marker.

Emoji-based giveaway detection is intentionally heuristic. A normal bridged message containing one of the same distinctive emoji may theoretically receive the corresponding visual treatment.

The bot-only `#announce` / `#pre` rules only hide preview UI. CSS cannot prevent The Lounge from performing server-side prefetch/network requests.
